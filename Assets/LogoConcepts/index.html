WhisprGo mark: four directions

Every option keeps the brand's one rule: monochrome, with the dot as the only ornament. Each mark is a live system with four states — idle, listening, transcribing, done — driven by springs, so any state change can interrupt any other. Hold space (or press and hold an icon) to speak.
